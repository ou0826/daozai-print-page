# 岛仔「打印进度」页 — 接入说明

给 Daozai（岛仔）加了一栏**打印进度**：展开小岛切到这一页，就能看到拓竹打印机的实时百分比、层数、剩余时间、喷嘴/热床温度和告警。

两边的改动都是**纯增量**，没有改动任何既有功能的逻辑。

---

## 一、为什么不是"插件"

先看过作者留没留插件空间，结论是**没有**：

- 全仓库 grep `plugin / 插件 / 动态加载`：命中的全是 `vendor/egui`、`vendor/eframe` 和第三方常量，**没有插件注册表、动态库加载或事件总线**。
- 唯一的"用户可跑代码"的口子是 `src/relay_script.rs`（中转站额度自定义脚本，靠已依赖的 `rquickjs`），但它只产出 AI 额度面板的私有字段，画不了任意 UI。
- 上游 commit `e080728`（作者本人）只加了 `.github/ISSUE_TEMPLATE/`：把「显示个人关心的数据（监控、倒计时…）」这类需求**导向插件**，并指向 issue #138。
- 而 #138 是**社区用户的提案**，不是设计文档；作者没给架构回复。全历史搜 `plugin` 零命中，`main` 只有一条分支，最新 tag v0.6.65 就是当前源码。

也就是说：**方向已官宣，机制不存在，规范不存在，时间表不存在。** 所以这次是按"将来能整块搬进插件"的形状做的——取数与渲染都收在一个模块里，中间是 JSON 契约。

## 二、数据怎么走

```
打印机 ──(MQTT 局域网/云端)──> 拓竹打印监控 (Python)
                                    │  只读本地状态桥 GET 127.0.0.1:39778/status
                                    ▼
                             岛仔「打印进度」页
```

- 岛仔**不碰打印机、不存打印机凭据**，只读本机回环地址上的 HTTP。
- 桥只监听 `127.0.0.1`、只有 GET、没有写接口。
- 端口默认 39778，被占用会往后试；实际端口写在 `%APPDATA%\BambuMonitor\rt\bridge.json`，岛仔会自动发现。


页面观感与「专注」页同源：环形进度 + 大字号百分比，颜色跟状态走（打印中绿 / 暂停黄 / 完成蓝 / 失败红）。四种状态都处理了：

| 状态 | 显示 |
|---|---|
| 正常打印 | 进度环、文件名、状态·阶段、层数·剩余、温度、告警或 AMS 行 |
| 暂停 / 故障 | 同上，黄/红环 + 状态点 + 「打印机告警 N 项」 |
| 桥在、打印机离线 | 保留上次画面并压暗，提示「打印机离线」 |
| 桥不在 | 「未连接打印监控」+ 端口 + 重试按钮 |

- 关闭页面后**不再轮询**；监控没开时按退避拉长间隔（最多 30 秒），不会每秒敲端口。
- 设置 → 打印：可看连接状态、桥地址、立即刷新。
- 页面开关与排序都在「设置 → 页面管理 → 打印」里。

用法：应用补丁 `daozai-print-page.patch`，或直接用这份已经改好的 `E:\Vibecodings\Daozai\src`。

```powershell
cargo build --locked --release --bin daozai     # 产物 target\x86_64-pc-windows-msvc\release\daozai.exe
```

开发和测试记得隔离数据目录：

```powershell
$env:DAOZAI_DATA_DIR = Join-Path $env:TEMP 'daozai-dev'
cargo test --locked --all-targets --features record -- --test-threads=1
```

## 五、验证过什么

1. **桥**：`python tests/test_bridge.py` 全绿（快照透传、`/health`、未知路径 404、端口冲突自动换端口）。
2. **真实链路**：起真实的 App（绕开单实例锁），它连上云端 MQTT 后，`curl 127.0.0.1:39778/status` 返回**真实打印机数据**（A1 mini、任务名、100%、125/125 层）。
3. **岛仔取数**：`DAOZAI_BAMBU_PORT=39778 cargo test reads_the_live_bridge -- --ignored --nocapture` 读到同一份真实数据。
4. **渲染**：`DAOZAI_BAMBU_PREVIEW_DIR=目录 cargo test bambu_gallery -- --ignored` 导出四种状态的实拍图（就是 `daozai-previews\bambu-*.png`），走的是产品同一套 `App::frame()`。
5. **全量测试**：`cargo test --locked --all-targets --features record -- --test-threads=1`。

## 六、已知边界

- 页面只读：没有暂停/继续/调温按钮（要动打印机就走监控或 Bambu Studio）。
- 收起态的常驻栏（类似天气的「🌧 9°」）这次没做，属于第二批改动。
- 桥依赖监控进程；监控不开时这一页显示「未连接」，其它功能不受影响。
- 打印机的实时画面（摄像头/缩略图）没接：需要额外拉 MJPEG，属于独立话题。
